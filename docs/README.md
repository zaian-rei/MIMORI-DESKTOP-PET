# Mimori documentation

Mimori is a Godot 4.7 desktop companion for Windows, Linux, and macOS. The project source is in the repository root; user downloads are attached to GitHub Releases.

For the current overview and install steps, start with the [project README](../README.md). Other documents in this folder describe architecture, settings, pets, themes, plugins, and contributor workflows. Design-reference files in `references/` are local working material and are not part of the public source release.
