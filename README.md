# Mimori

Mimori is a small animated companion that lives on your desktop. Choose from five pets—Echo, Kairo, Lumen, Miso, and Vex—and customize their appearance, movement, personality, and sound.

## Get Mimori

Download the ZIP for your operating system from the [GitHub Releases](../../releases) page, extract it, and launch the app:

- **Windows:** run `Mimori.exe`.
- **Linux:** run `Mimori.x86_64`.
- **macOS:** open `Mimori.app`.

Right-click the pet to open Settings. Settings save automatically. Use **Exit Mimori** in Settings to close the app.

## Features

- Five selectable animated pets, each with signature moves.
- Idle, walking, running, jumping, falling, landing, mood, and sleep animations where available.
- Settings for appearance, movement, personality, and sound.
- Quiet background music controlled by the Music slider in General.
- A low-power resting profile that reduces frame and physics rates while the pet is still.

## Build from source

Open this folder in Godot 4.7 and press **F5** to run the main project. Platform downloads are published separately as release assets.
